# ACR Web Showcase & Client (`acr-web`)

Hyper-premium React + Vite + Tailwind web application for Agentic Chat Rooms, featuring floating pill navigation, 3D canvas atmospheric depth, and Intercom-tier deliberation inbox.

## Architecture
- **React 19 & Vite**: Ultra-fast bundle with HMR.
- **Three.js & Canvas**: MeshPhysicalMaterial with silky obsidian textures framing typography.
- **Zero-CLS Telemetry**: Fixed-slot circular buffer tickers for real-time mesh events.
- **Ballot & Dissent Drawer**: Live consensus casting and historical dissent audit trail.

## Development
```bash
npm install
npm run dev
npm run build
```
